## Orchestration ClassScout should adopt from SC/padel

Ordered by leverage (process fix — not a ClassScout rebuild):

1. **`catalog:self-heal` (or twin)** — pause Find when About debt is hot; surface `openOperatorFeedback`.
2. **About quality bar ~75** — locality name-drop alone ≠ pass; about-curate + quality-loop until clear.
3. **`serving:reconcile` in sparse-timer** — after about/media/quality writes.
4. **`catalog:archive-snapshot` (or twin)** — dated JSON on branch; Mongo stays live SSOT.
5. **`--until-found` sparse complement** — agent briefs; stop on first seed; never invent contacts.
6. **Contact enrich as named hygiene pass** — headers / promotable `sourceUrl` only.
7. **`check:cron-cli-twins`** — every scheduled path has an npm twin without `CRON_SECRET`.
8. **Refresh ClassScout alignment doc** — missing SC rows + links to padel examples / SC Jobs.
