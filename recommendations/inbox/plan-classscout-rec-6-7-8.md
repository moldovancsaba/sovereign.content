## Why each helps (and what we will *not* do)

### #6 — street-address vocabulary + copy-chrome detectors

**Helps because:** our engine still lacks ClassScout’s `isStreetLevel` gate (see management
`docs/specs/classscout-lib-geo-city-spec*.md`). Hygiene ticks leave geo candidates unresolved when
`line1` is mall/prose junk or neighborhood-only. About chrome already uses
`validatePublicDescription`, but ClassScout found extra patterns (`{template_tokens}`, leading
Contact-form chrome) we should share.

**Will not:** invent African street tokens from thin air; copy NYC-only vocabulary as the *only*
accept list. Reference ClassScout extractors, then add Africa-relevant accept/reject samples
(mall concourses, “Sports Village”, Western Bypass, Fields Mall) without inventing venues.

### #7 — ClassScout `catalog:*` job alias twins

**Helps because:** agents reading this SSOT must call ClassScout without learning a second dialect.
ClassScout’s thin npm twins + alignment doc are the right pattern.

**Will not:** rename SC job contracts, or add redundant aliases inside `management` — padel-africa
already *is* the native `catalog:*` vocabulary. Implementation here is documentation + a pointer.

### #8 — media-curate `generated_art_only` policy hook

**Helps because:** portable contract must support verticals that forbid venue-photo scrape
(ClassScout generated art). Without a named policy, adopters either violate product rules or fork
the job.

**Will not:** switch Padel Africa to generated-art-only. Our live Improve/Find test applied OG /
website media to Botswana listings under the default scrape path — keep that as default.

## Phase A — SSOT (this repo → `main`) — do first

1. **Jobs — street-line + weak-copy contract** (absorbs #6 docs)
   - Accept: Court/Ct, Terrace/Ter, Concourse, Square, Circle, Island, bare Pl (after CSS reject),
     capitalized `… Way`, hyphenated borough/district forms, spelled house numbers, venue-prefix
     peel, `&` / `at` / `and` intersections.
   - Reject: dual-site blurbs, prose lowercase “way”, CSS utility strings, PO-box-only as street.
   - Weak-copy: unresolved `{template_tokens}`, leading Contact-form chrome, consent-banner false
     positives (alongside existing URL / Sources / cookie chrome).

     not download venue photographs. Host hierarchy still applies to generated bytes.
   - `allow_og_scrape`: current website OG → page snapshot → R2 → ImgBB → https passthrough.

## Phase B — `management` / padel-africa (feature branch → `release/padel-africa`)

### B1. Street + chrome (#6) — code

1. Add `isStreetLevel(address)` (or equivalent) next to geo backfill — reject PO-box-only and
   non-street `line1` before Nominatim spend.
2. Port / share street-type accept+reject tables from ClassScout reference; add Africa fixtures
   (mall / sports-village / bypass) as tests, not invented catalogue rows.
3. Extend `descriptionQuality` chrome table: `{…}` template tokens, leading Contact-form chrome;
   keep locale-scoped lists.
4. Wire validators into `catalog:about-curate` / quality improve paths (already call
   `validatePublicDescription` — expand rules, not a second pipeline).
5. Tests: ClassScout-style Court/Terrace true-positives; CSS/prose “way” true-negatives; Africa
   mall line1 samples; chrome unit tests.

### B2. Media policy hook (#8) — code

1. `runMediaCurate` / CLI: `--policy allow_og_scrape|generated_art_only` (env override
   `MEDIA_CURATE_POLICY` optional).
2. Default for padel-africa: `allow_og_scrape`.
3. `generated_art_only` path: scan public listings, report `withHostedImage` /
   `missingHostedImage`, apply=0 for scrape; optional generate-and-host only if product later
   enables it (out of scope until requested).
4. JSON summary always includes `policy`.
5. Unit/dry-run tests for both policies.

### B3. Alias twins (#7) — management

**No code.** Optional one-liner in `docs/dual-repo-workflow.md` / `docs/operations.md` pointing at
ClassScout alignment for cross-vertical agents. Padel scripts already use native `catalog:*`.
